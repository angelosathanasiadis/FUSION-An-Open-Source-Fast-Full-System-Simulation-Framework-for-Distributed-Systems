# FUSION-A-Distributed-Framework-for-Full-System-and-Packet-Level-Network-Co-Simulation

## Abstract
Simulating modern distributed systems requires holistically combining accurate software execution with realistic network behavior. Existing tools typically evaluate compute and network subsystems in isolation, or suffer from prohibitive computational overhead when attempting full-system co-simulation. This paper presents FUSION, an open-source, fully distributed co-simulation framework that integrates full-system QEMU emulation with the OMNeT++ network simulator via the IEEE High-Level Architecture (HLA) standard. By introducing an Adaptive Synchronization Strategy and an automated multi-federated deployment layer, the framework effectively balances orchestration overhead and efficiently scales across distributed clusters. We evaluate FUSION using complex real-world workloads, including Iperf, the HPCG benchmark, and LLaMA.cpp inference. Results demonstrate that FUSION maintains high network fidelity and achieves an order-of-magnitude reduction in simulation time compared with state-of-the-art cycle-accurate frameworks, enabling rapid and accurate evaluation of massive distributed systems.

## Core Contributions

The contribution of this paper can be summarized in the following points:A QEMU integration for HLA-coordinated full-system and packet-level network co-simulation. We integrate instruction-counted full Software (SW) stack execution, virtual CPU progression, device events, and Ethernet-frame exchange with HLA time management. We developed mechanisms that intercept outgoing Ethernet frames and reinject incoming frames at QEMU's emulated NICs.An explicit execution coordination scheme and analytical characterization of synchronization-induced packet timing. We define the conditions under which HLA time authorization and packet-delivery completion jointly allow for efficient software execution. The resulting coordination scheme provides sufficient conditions for preserving causal ordering across the compute and network domains. We derive the transmission timestamp displacement, $\delta_{tx} \in [\lambda, \tau + \lambda]$, connecting synchronization granularity to communication timing. This analysis makes the synchronization interval an explicit modeling parameter and provides a basis for interpreting its effects on distributed application progress.A configurable execution and deployment workflow for distributed QEMU co-simulation. Utilizing a developed HLA federation architecture, we provide QEMU-specific orchestration for automated node configuration, host placement, and allocation of federations to multiple HLA gateways. A configurable synchronization scheme establishes an explicit transition from non-important processes (e.g. OS boot/preparation) to synchronized execution. Together, these mechanisms support repeatable experiments in which compute placement, middleware allocation, and initialization policy can be configured independently of the simulated network topology.A quantitative investigation of the interaction between synchronization, deployment, and workload behavior. Communication benchmarks, HPCG, and distributed inference with llama.cpp demonstrate how synchronization granularity affects execution cost and application progress. The evaluation demonstrates high scalability up to 128 nodes, efficient multi-host distribution, and an order-of-magnitude speedup over an existing similar simulator.
